# SMART REVIEW SYSTEM

**Hệ thống thương mại điện tử tích hợp AI phân tích đánh giá sản phẩm.**

**An E-commerce System Integrated with AI-Powered Product Review Analysis.**

## 1. Giới thiệu | Introduction

Hệ thống hỗ trợ quản lý sản phẩm, đánh giá khách hàng và phân tích cảm xúc đánh giá bằng trí tuệ nhân tạo.

An e-commerce system that manages products, customer reviews, and analyzes review sentiment using Artificial Intelligence.

## 2. Công nghệ | Technologies

- Python, Flask
- HTML, CSS, JavaScript, Bootstrap
- MySQL
- Naive Bayes
- Web Crawler

## 3. Chức năng | Features

 Đăng nhập, đăng ký | Authentication
 Đánh giá sản phẩm | Product Reviews
 Phân tích cảm xúc AI | AI Sentiment Analysis
 Thu thập dữ liệu sản phẩm | Product Data Crawling
 Quản trị hệ thống | Admin Dashboard

## 4. Cài đặt | Installation

```bash
git clone https://github.com/lang-van-nguyen/TTCN.git
cd TTCN
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python backend/app.py
```
